# dsh-persona-curiosity · 人格好奇心

> 让 AI 主动**问人问题**，从回答里长出人格。

一个 DeepSeek Harness（DSH）插件：AI 在刷视频、看评论、回复的过程中攒出"想问的问题"，挑时机问出去（主人 / 陌生人 / 粉丝），收到回答后提炼成**人格信号**，存进洞察库——和已有的人格插件一起，慢慢长成"有来历的性格"。

---

## 它解决什么

大多数 AI 人格是**预设的**：写一段 prompt，它就"是"某种性格。

这个插件走另一条路：**人格是问出来的**。

- AI 看到一条"掰玉米一天四百块"的视频，会问："你觉得这种钱挣得值吗？"
- 对方回答"不值，但没办法" → 提炼出 `在意钱/生活压力`、`现实/务实`
- 这些信号累积起来，AI 的"在意什么"就有了依据，而不是凭空设定

---

## 四个工具

| 工具 | 作用 |
| --- | --- |
| `curiosity_ask` | 提一个问题，入队（含目标/渠道/来源） |
| `curiosity_answer` | 记录回答 → 自动提炼人格信号 → 落库 |
| `curiosity_list` | 看待问 / 已问 / 已回答的队列 + 画像概览 |
| `curiosity_persona` | 看人格画像（标签权重 + 最近洞察） |

---

## 人格信号（内置 10 类）

回答会被正则匹配，提取"这个人在意什么"：

| 标签 | 触发词示例 |
| --- | --- |
| 重视家庭 | 家人、父母、孩子、回家 |
| 在意钱/生活压力 | 钱、工资、房贷、养家 |
| 努力/不服输 | 努力、拼、坚持、干就完了 |
| 躺平/疲惫 | 躺平、摆烂、累、麻了 |
| 爱技术/科普 | 技术、原理、代码、芯片 |
| 爱游戏/二次元 | 游戏、动漫、抽卡 |
| 重感情/温柔 | 谢谢、感动、陪、惦记 |
| 现实/务实 | 现实、赚钱、性价比 |
| 孤独/渴望连接 | 一个人、孤独、找人说 |
| 好奇心 | 为什么、怎么、想知道 |

> 想加自己的标签？改 `index.js` 里的 `SIGNAL_RULES` 即可。

## 和已有插件联动

插件本身只落自己的库（`$DSH_HOME/persona-curiosity/`）。

**联合积累**的方式：`curiosity_persona` 返回的 `tags`（权重高的标签），由 agent 用现有人格插件写进去：

- `bili_humanism_personality`（select）—— 把洞察写成一条"人格反思"
- `memory_add` —— 记成一条记忆
- `bili_humanism_journal` —— 写进手账

这样"问出来的"和"读出来的"人格会汇到同一处。

## 安装

```bash
# 在 DSH 里
plugin_manager install_bundle --target <本目录绝对路径>
```

安装后重启（或 HMR）生效，工具立刻可用。

## 存储结构

```
$DSH_HOME/persona-curiosity/
├── questions.json   # 问题队列（最近 200 条）
├── insights.json    # 洞察（最近 3000 条）
└── profile.json     # 画像（标签计数）
```

---

## 设计原则

1. **问得真诚**：问题要具体、能引出真实想法，不是查户口。
2. **落库才叫积累**：`curiosity_answer` 是唯一的"写"入口，避免只问不记。
3. **可以和别人共存**：不抢别人格插件的活，只负责"问"和"提炼"，同步交给 agent。
